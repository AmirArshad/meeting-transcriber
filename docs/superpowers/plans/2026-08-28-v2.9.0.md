# AvaNevis v2.9.0 Implementation Plan

> **For agentic workers:** Execute inline by default. Use a subagent only when the user requests it or the task crosses high-risk platform/process boundaries.

**Goal:** Ship v2.9.0 as a local-first maintenance and UX release: resolve the Linux FileLock inconsistency, accept only proven compatible dependency upgrades, refresh the renderer visual system, and complete bounded reliability follow-through without beginning Linux AI add-ons or cloud sync.

**Architecture:** Treat dependency upgrades as platform-specific compatibility work, not bulk version churn. Keep Electron 44 in an independent lane because it changes Chromium/Node/runtime behavior. Preserve the existing three-tab renderer and establish only semantic layout/action boundaries for future meeting objects; no sync product behavior or persistence is added.

**Tech Stack:** Electron 42 baseline / Electron 44 candidate, electron-builder 26.15.3, plain HTML/CSS/JS, Node.js CommonJS, Python 3.11, faster-whisper, MLX Whisper, Speakrs, PyObjC, PyAV, GitHub Actions.

## Global Constraints

- v2.9.0 supports Windows x64, macOS 13+ arm64, and Linux x64 Core Beta; Omarchy is supported and other Linux distributions remain experimental.
- Privacy is non-negotiable: no cloud transcription, telemetry, background uploads, or network dependency beyond explicit model/update checks and build-time downloads.
- Linux stays CPU `faster-whisper`; Linux CUDA, Speakrs, Pyannote, and summaries remain greyed `unsupported`. Do not start Linux phases 6–9 before v3.0.
- Keep Python 3.11 runtime/build compatibility and preserve CUDA/MLX/Whisper/Speakrs package and packaged-runtime behavior.
- Do not add Apple Developer signing or notarization. Retain existing ad-hoc macOS bundle checks.
- Electron 44 is a standalone acceptance decision. Do not combine it with unrelated high-risk Python/runtime upgrades.
- Do not add meeting sync UI, account data, network calls, transfer state, or meeting-schema changes. See `docs/initiatives/MEETING_OBJECTS_AND_PRIVATE_SYNC.md`.
- Version and release metadata change only on `release/v2.9.0`, after every accepted lane is independently green.
