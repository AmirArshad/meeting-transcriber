# v2.8.0 Linux Core Beta Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Promote the reviewed Linux Core Beta release candidate as AvaNevis v2.8.0 with accurate release metadata.

**Architecture:** This is a metadata-only release promotion. The candidate’s recorder, device, packaging, updater, and privacy behavior are already implemented on `release/linux`; the release commit only aligns version files, captures curated release notes, corrects in-progress documentation, and absorbs the compatible `filelock` patch.

**Tech Stack:** Node/Electron package metadata, Python requirement pins, Markdown release documentation, GitHub Actions release workflow.

**Spec:** User request of 2026-08-28 to merge the release branch to `master`, create v2.8.0, and triage the open Dependabot PRs.

## Global Constraints

- Version must be exactly `2.8.0` in `package.json` and `package-lock.json`; release tag must be `v2.8.0`.
- Linux remains an x86_64 Core Beta: Omarchy 4 is supported; other listed distributions are experimental; CPU `faster-whisper` only; AI add-ons remain unsupported.
- Do not alter the pinned Electron 42 line, the macOS `torch==2.12.0` / `setuptools<82` compatibility constraint, or reproducible Windows runtime pins in this release.
- Use only the compatible patch-level Dependabot update: `filelock` 3.32.0 → 3.32.3 across every declared runtime/development requirement.
- Merge/tag only after the release commit has fresh successful CI evidence.
