## Recommended order

Work in three lanes. They can overlap; they are not a single global queue.

### Lane 1 — start without hardware qualification

These do not expose a new model or claim a new language/runtime.

1. **Settings and navigation presentation** ([plan](2026-09-07-settings-navigation-shortcuts.md) slice A): Linux Speakrs as static text, enable/disable wording, AI Add-on log timestamps, Record rail icon, Speakrs removal that leaves Hugging Face tokens untouched.
2. **Keyboard shortcuts** (same plan, slice B): app-focused chords, then packaged conflict checks on Windows, macOS, and supported Linux.
3. **Click-away meeting rename:** write a short design first (out of scope for the Settings plan), then implement. No model investigation.
4. **Whisper choice policy** ([plan](2026-09-07-language-model-policy-whisper-large.md) slice A): remove Persian, Tiny, and Base from **new** selections; migrate saved Tiny/Base to Small; keep pending jobs on their saved language/model. Does not require downloading Large or scoring other languages.

### Lane 2 — investigations (eight remaining)

Run these before the matching feature ships. CPU evidence does not qualify CUDA, and the reverse is also true. Linux summaries and some add-ons stay gated on managed CUDA; skip those Linux rows when the gate fails, and do not invent a CPU fallback.

| # | Investigation | Where to run it | Blocks |
| --- | --- | --- | --- |
| 1 | Parakeet model/runtime vs Whisper Small on English audio | Windows x64 CPU and admitted CUDA 12; Apple Silicon macOS; Linux x86_64 CPU and managed CUDA, independently | Optional Parakeet engine on that platform |
| 2 | Whisper Large v3 identity, cache/download, RAM/VRAM, ordinary and guided timings | Same three platform/runtime rows as (1) | Exposing Large |
| 3 | Other listed transcription languages (not Persian) | Representative local fixtures plus fluent review on the relevant Whisper runtime. Test Mandarin and Cantonese separately; one `zh` code is not both. | Extra language removals |

| 6 | Alternative summary models vs installed Qwen 9B | Same GPU rows as (4). Start with catalog 4B/14B entries, then a short newer-GGUF list. Keeping Qwen is valid. | Replacing Qwen or adding a model selector |
| 7 | PipeWire/PulseAudio microphone reset to 50% | Supported Omarchy/CachyOS Linux desktop session only | Any app-side or setup-side volume change |
| 8 | Inference performance on Windows and Linux | Only if a speed default is still being pursued. Apple Silicon already rejected the tested encoding, Whisper, and smaller-context candidates. | Changing those production defaults |

Create public notes during those investigations (`PARAKEET_COMPATIBILITY.md`, `V2_10_LANGUAGE_MODEL_QUALIFICATION.md`, `V2_10_SUMMARY_QUALIFICATION.md`). Do not commit user recordings, transcripts, prompts, tokens, scratch report directories, or home-directory paths. Identify hardware class, OS, app revision, and artifact hashes.

### Lane 3 — implement after the matching investigation

- **Parakeet:** after (1) pins a runtime per platform. Unqualified combinations stay unavailable. [Plan](2026-09-06-parakeet-integration.md).
- **Whisper Large:** after (2). Independent per platform/runtime is acceptable. [Plan](2026-09-07-language-model-policy-whisper-large.md) slice B.
- **Further language removals:** after (3) and a product review. Persian removal does not wait on this.
- **Summary language UI and enforcement:** after (4), and (5) if output language will be enforced. [Plan](2026-09-07-summary-languages-and-models.md) slice A.
- **Summary model selector or replacement:** after (6), only if a candidate qualifies. Slice B.
- **Inference default changes:** none are qualified today. Reopen only with (8) plus the quality gates in the [inference plan](2026-09-06-inference-performance.md). Persistent workers need their own design.
- **Linux volume behavior:** only after (7), and only if a remedy is safe.

Packaged acceptance still happens on Windows 10/11 x64, Apple Silicon macOS 14+, and supported Omarchy/CachyOS Linux. CI is not hardware acceptance.
