not per-platform quality, timing, or memory qualification. Users decide whether
it suits their hardware. Qwen languages need practical checks with the current
model on one runtime, without repeating language-quality evaluation per OS.
These decisions supersede qualification depth and exposure gates in older
designs and sequencing below. Preserve existing runtime integrity/admission,
local-only inference, explicit setup, queue/cancellation, and output preservation.

Recording/encoding assessment is dropped from v2.10; Linux microphone volume
remains. The four deferred Parakeet lifecycle checks remain release work.

Use this page for **order and remaining investigations**. Use each feature plan for behavior, files, and tests. Use `todo.md` to check items off.
