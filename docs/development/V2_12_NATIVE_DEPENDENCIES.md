## Cargo audit

Using installed `cargo-audit 0.22.2`, the CI version, both commands exited 0 on 2026-11-18 with `--deny warnings` and 1,533 advisory records loaded:

- `cargo audit --deny warnings --file native/speakrs-cli/Cargo.lock` (110 dependencies).
- `cargo audit --deny warnings --file native/speakrs-cpu-smoke/Cargo.lock` (72 dependencies).

[crates.io](https://crates.io/crates/cargo-audit) lists cargo-audit 0.23.0. A tool update requires checking Rust toolchain compatibility and running the same CI job; it is not evidence that application dependencies are qualified. The audit covers the lockfiles, not downloaded ONNX/CUDA binaries, native toolchains or model artifacts.

## CI and build tools

The release and CI workflows pin action source revisions. Upstream latest-release API comparisons on the survey date matched the versions documented in the workflow comments: `actions/checkout` 7.0.1, `setup-node` 7.1.0, `setup-python` 7.1.0, `cache` 6.1.0, `upload-artifact` 7.0.2, `download-artifact` 8.0.2, `Swatinem/rust-cache` 2.9.3, `softprops/action-gh-release` 3.0.4, `markdownlint-cli2-action` 25.0.0 and `github-action-markdown-link-check` 1.0.17. See [GitHub Actions releases](https://github.com/actions) and each action's own release page. The `dtolnay/rust-toolchain` action is SHA-pinned and installs Rust 1.89.0 explicitly; its floating v1 release does not establish a newer compatible immutable revision. Recheck tag-to-SHA mapping and execute affected jobs before changing action revisions.

`cargo-audit` is pinned to 0.22.2 and `pip-audit` to 2.10.1. CI installs flake8 without a version and upgrades pip without a version; these are moving CI tools, not shipped application pins. Review their resolved versions and constraints when qualifying CI reproducibility. Node 24 and Python 3.11 are major/minor selectors in setup actions, while Rust is 1.89.0. The release runners and Swift compiler version also need a matching-host record. No CI job was run in this survey.
