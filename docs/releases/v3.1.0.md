# AvaNevis v3.1.0

AvaNevis 3.1.0 is a private, local Audio Recorder & Transcriber for microphone, desktop audio, and imported audio files, adding streaming grounded Chat with smarter local retrieval, 11 recording tags with dedicated summary templates, non-destructive speaker naming with voice previews, a multi-model Summaries & Chat library, and updated dependencies.

- **Streaming grounded Chat & smarter local retrieval:** Local Chat streams answers live over authenticated loopback `llama-server` (`llama-cli` fallback) with a **Stop** button, honest recovery/empty states, an enlarged recording selector with right-aligned short timestamps, and improved date, entity, tag, and follow-up retrieval. Strict fail-closed citation verification remains enforced while preserving full Markdown formatting in answers and drafts.
- **11 recording tags & tag-aware summary templates:** Categorize recordings as Meeting, Appointment, Phone / Support Call, Interview, Lecture / Study, Podcast, Video, Voice Note, Brainstorm, Music, or Other from Record, Import, Activity, History, or Prepare summary. Filter History and Chat by tag, generate summaries tailored to each recording type (`tag-templates-v1`), and get a non-blocking regeneration notice if a recording's tag changes later.
- **Speaker naming with voice previews:** Rename `Speaker 1` / `Speaker 2` to real names inline in History or inside Prepare summary, with one-line transcript excerpts and timestamped voice-preview playback. Speaker names are stored as a non-destructive metadata overlay that preserves saved `.md` transcripts and `.captions.json` hashes on disk while updating History, FTS5 search, Chat citations, summaries, and `.md`/`.txt`/`.srt`/`.vtt` (`<v Name>`) exports.
- **Multi-model Summaries & Chat library:** Install and manage multiple local models in Settings — **Qwen3.5 9B**, **Qwen3.5 4B**, **Gemma 4 E4B**, and **Gemma 4 12B** — with shared `llama.cpp` runtimes, device-fit preflight checks, per-thread and per-run model selection, single-slot exclusive execution with **Free memory** unload, and managed removal that preserves recordings, summaries, and Chat threads. Gemma 4 E4B and 12B enable English summaries on Apple Silicon (`summary-language-v3`); Qwen3.5 9B keeps its qualified summary languages; **Inkling 2 Mini** remains gated pending a published `llama.cpp` release containing the loop-layer scale fix and native qualification.
- **UI polish & dependency/security updates:** Cross-view alignment, control sizing, spacing, and copy polish across Record, History, Chat, and Settings, plus updated npm security overrides (`brace-expansion`, `undici`), Python 3.11 patch pins (`av==18.1.1`, `PyYAML==6.0.4`, `pydantic==2.14.4`, `pydantic-core==2.50.5`, `certifi==2026.11.20`, macOS `regex==2026.11.19`), Rust `1.89.0` lockfile patch updates, and a regenerated bundled Python SBOM (`legal/PYTHON-BUNDLED-PACKAGES.md`) with zero audit findings.

### Installation

- **Windows (unsigned installer):** Download and run `AvaNevis-Setup-3.1.0.exe`. Because the v3.1.0 Windows installer is unsigned, Windows Defender SmartScreen may warn on first run — choose **More info** then **Run anyway**.
- **macOS (Apple Silicon, macOS 15+, ad-hoc signed & not notarized):** Download `AvaNevis-Setup-3.1.0.dmg` and drag AvaNevis into Applications. Because v3.1.0 macOS builds are ad-hoc signed and not notarized, if Gatekeeper blocks launch, open **System Settings → Privacy & Security → Open Anyway** after attempting to open it (<https://support.apple.com/en-us/102445>). Grant Microphone and Screen & System Audio Recording permissions when prompted.
- **Linux (x86_64 Core Beta):** Run the `AvaNevis-Setup-3.1.0.AppImage`, install `AvaNevis-Setup-3.1.0.pkg.tar.zst` on Arch/CachyOS/Omarchy (`sudo pacman -U ...`), or try the experimental `.deb` (`sudo apt install ./AvaNevis-Setup-3.1.0.deb`).

Electron remains on `46.0.0-alpha.11` (stable Electron 46.x is still unpublished as of 2026-11-22) and FFmpeg remains on matched `8.1.2` across all three platforms. See the qualification record for macOS arm64, CachyOS Linux, and Windows 11 evidence, dependency holds, and the explicitly accepted v3.1.0 limits: Windows 10, macOS 15, Omarchy-specific hardware checks, interactive Linux desktop/system-package checks, full cross-platform multi-model/Inkling matrix checks, disposable-runner installer install/uninstall verification, live signed updater verification, and optional code signing/notarization remain unqualified or deferred.
