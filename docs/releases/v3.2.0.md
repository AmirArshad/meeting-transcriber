# AvaNevis v3.2.0 (Draft)

> **Status:** Draft prepared on `release/3.2` prior to final cross-platform native qualification and version cut (`package.json` remains `3.1.0`). Update `[PENDING NATIVE QUALIFICATION]` sections before tagging `v3.2.0`.

AvaNevis 3.2.0 is a private, local Audio Recorder & Transcriber for microphone, desktop audio, and imported audio files, adding smarter 3-tier Chat retrieval with recording-free General chat, improved device-fit calibration and unload-before-download prompts, ≥5-second speaker voice samples, an always-available Summary format picker, Structured JSON transcript export (`.json`), and an expanded local model catalog on the unified `llama.cpp` runtime.

- **Smarter Chat context, granular citations & General chat mode:** A new 3-tier local context router loads full recording transcripts directly when they fit within the model's context budget, resolves conversational follow-ups across turns with entity carry-over and rolling compaction, and preserves granular timestamp citations alongside `Title · Summary` labels. An explicit **No recordings (General chat)** scope and **Clear recording context** action allow private local AI assistance with clear mode guardrails and zero fabricated citations.
- **Expanded Summaries & Chat library & unified runtime:** Unblocks **Inkling 2 Mini** (`IQ4_NL`) on unified `llama.cpp` (`b12631`, or `[PENDING NATIVE QUALIFICATION: update if bumped]`), adds **Bonsai 2 9B** (`Q2_0`), **Bonsai 2.5 27B** (`Q2_0`, replacing retired Bonsai 2 27B while preserving existing installed profiles and migrating uninstalled threads), **Ministral 3 14B**, **Gemma 4 26B-A4B**, and **Qwen 3.8 27B** for device-gated local Chat setup, and refines Gemma 4 12B / 12 GB VRAM fit detection (`likely_fits` / `tight` / `needs_more_memory`) with an in-app **Unload & Continue** prompt when a loaded Chat model holds needed graphics memory.
- **Speaker voice samples & always-available Summary format picker:** Prefers ≥5-second speech segments for speaker preview playback with a clear **Sample** caption, and keeps the **Summary format** selector available in Prepare summary for both tagged and untagged recordings without silently changing a recording's saved tag.
- **Structured JSON transcript export (`.json`):** Adds schema-versioned (`avanevis-transcript`) `.json` export alongside `.md`, `.txt`, `.srt`, and `.vtt`, bundling recording metadata, optional speaker labels, Markdown and plain-text transcript with `sourceTranscriptHash`, validated caption cues when available, and completed summary data while omitting host filesystem paths.
- **Lifecycle hardening & dependency maintenance:** Hardens updater restart cancellation (`Keep App Open` during active recording), protects installed legacy model threads from unexpected migration on transient errors, serializes Linux CUDA probes across active GPU runtime operations, and incorporates npm/Python/Rust security updates with clean audits (`[PENDING NATIVE QUALIFICATION: summarize final dependency pins at release cut]`).

### Installation

- **Windows (`[PENDING NATIVE QUALIFICATION: signing status]`):** Download and run `AvaNevis-Setup-3.2.0.exe`. If unsigned, Windows Defender SmartScreen may warn on first run — choose **More info** then **Run anyway**.
- **macOS (Apple Silicon, macOS 15+, `[PENDING NATIVE QUALIFICATION: signing status]`):** Download `AvaNevis-Setup-3.2.0.dmg` and drag AvaNevis into Applications. If ad-hoc signed and not notarized, open **System Settings → Privacy & Security → Open Anyway** if Gatekeeper prompts (<https://support.apple.com/en-us/102445>). Grant Microphone and Screen & System Audio Recording permissions when prompted.
- **Linux (x86_64 Core Beta):** Run `AvaNevis-Setup-3.2.0.AppImage`, install `AvaNevis-Setup-3.2.0.pkg.tar.zst` on Arch/CachyOS/Omarchy (`sudo pacman -U ...`), or try the experimental `.deb` (`sudo apt install ./AvaNevis-Setup-3.2.0.deb`).
