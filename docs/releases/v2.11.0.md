# AvaNevis v2.11.0

AvaNevis 2.11.0 upgrades local speaker identification to Speakrs 0.7 and moves
secure token storage to Electron's asynchronous API. Processing remains local.

## Changes

- Use the native Speakrs 0.7 engine with CUDA on Windows and Linux and CoreML
  on Apple Silicon. Speaker setup downloads and verifies the platform's pinned
  model files explicitly; inference does not fall back to CPU or cloud services.
- Migrate existing Speakrs installations through verified, transactional setup.
  A failed or cancelled setup preserves the previous active installation.
- Update Electron to **46.0.0-alpha.10**, a prerelease, and use asynchronous
  safeStorage for speaker tokens. Linux rejects Electron's fixed-key fallback.
- Raise the packaged macOS minimum to **macOS 15**, on Apple Silicon. Windows
  installers remain unsigned; macOS builds are ad-hoc signed and not notarized.
- Refresh the development pytest minimum and the pinned release action.

## Upgrading

Install the new version on each machine. Recordings and model data remain in
user data. Existing Speakrs users may need to run **Repair** in Settings to
install and validate the new model files. Setup is explicit and requires a
supported accelerator. Pyannote remains available on Windows and macOS; its
user-provided token is retained when switching to or removing Speakrs.

## Validation and limits

The [qualification record](../development/V2_11_SPEAKRS_ELECTRON_QUALIFICATION.md)
describes the actual Linux RTX 4070, Windows RTX 4070 and macOS M4 Pro tests.
These include synthetic audio and native accelerator checks; they do not establish
natural multi-speaker quality. On 2026-11-16 the user accepted the documented
coverage limits, including waiving further testing on other macOS versions and
NVIDIA GPU tiers. Acceptance is not evidence that those configurations were
tested. Other untested flows and the unresolved transient Windows pending-
transcription banner are listed in that record. Electron 46 is an alpha, not a
stable Electron release.
