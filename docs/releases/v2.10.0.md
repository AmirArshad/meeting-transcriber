# AvaNevis v2.10.0

AvaNevis v2.10.0 adds optional English-only Parakeet transcription, Whisper Large
v3, checked transcript-language Qwen summaries, and Settings/navigation polish.
Manual acceptance was confirmed by the user on 2026-10-03; review fixes and
cross-platform CI passed before tagging. The
[Linux qualification report](../development/V2_10_LINUX_RELEASE_QUALIFICATION.md)
distinguishes user sign-off from measured automated evidence.

## Changes

- Optional English-only Parakeet v2 transcription on Windows CUDA, Apple Silicon
  Metal and Linux managed CUDA 12. Whisper remains the default. Capture-time
  engine selection is retained for queued work and recovery; unavailable engines
  fail closed rather than silently substituting Whisper or CPU.
- Whisper Large v3 is available through explicit model setup. Small remains the
  default and smallest new choice; Tiny/Base are retired from new choices and
  Persian is removed from the selectable language list. Existing Tiny/Base
  preferences move to Small; saved pending requests retain their original
  model/language selection.
- Current Qwen summaries support English, Spanish, French, German, Chinese,
  Japanese, Italian, Panjabi, Hindi, Korean and Portuguese. Each generation asks
  for an editable, hash-bound transcript-language confirmation. Local input and
  output language checks reject mismatched or indeterminate prose and preserve
  previous summaries on failure. Summary context budgeting now uses UTF-8 bytes
  to better bound multilingual prompts.
- Clearer Settings setup/remove wording, timestamps in the AI Add-ons log,
  Settings section navigation, Record rail icon/logo, click-away meeting rename
  and app-focused recording/navigation shortcuts. Removing Speakrs preserves a
  saved Hugging Face token; Pyannote removal retains its token-deletion behavior.
- Parakeet allocation failures now retain actionable memory/retry guidance even
  when runtime startup warnings precede the failure. Source audio and previous
  transcripts remain protected by guarded result commits.
- Parakeet compute admission verifies pinned runtime, model and VAD content before
  probing or inference. Windows packaged setup uses an isolated interpreter and
  pinned CUDA libraries; Apple Silicon uses Metal and Linux uses managed CUDA 12.
  Repair and removal remain available when an installed runtime is unusable.
- Successful transcript replacement invalidates obsolete speaker metadata. New
  speaker sidecars are bound to the committed Markdown hash, and summaries use
  speaker text only when that provenance matches the current transcript. Failed
  retries preserve previous transcripts and derived output.
- Interrupted-capture recovery durably retains the exact engine/model/language
  selection across restarts, including when finalization succeeds but its process
  response is lost. Recovery handoffs remain retryable until metadata acknowledges
  the saved request.
- Windows CUDA setup closes checksum streams before promoting staged files and
  retries transient directory locks, avoiding spurious setup/repair failures.
- Dependency and CI maintenance: electron-builder 26.16.1, adm-zip 0.6.1, updated
  npm override pins (including http-cache-semantics 4.3.0), and macOS urllib3 2.8.0.
  Cross-platform frontend regressions, Python checks, installer smoke checks and
  dependency audits passed, including the corrected Windows guided-retry test.

## Platform support

- Windows 10/11 x64.
- macOS 14+ on Apple Silicon; arm64 packages only. Packages remain ad-hoc signed,
  not notarized.
- Linux Core Beta: Omarchy 4 and CachyOS x86_64, Hyprland/Wayland + PipeWire.
  Other distributions/desktops remain [experimental betas](../guides/LINUX_EXPERIMENTAL.md).
  Release builds include AppImage, pacman and experimental deb artifacts; Linux
  package structure and bundled-runtime checks passed. The deb package has no new
  Debian/Ubuntu hardware acceptance claim.

All meeting processing remains local. Models/add-ons require explicit setup;
no telemetry, cloud processing or background uploads were added. Linux speaker
identification is Speakrs-only/CUDA-only; summaries require their own managed
CUDA admission. Parakeet has no CPU/cloud fallback. Other NVIDIA Linux hardware
remains best-effort beyond the recorded CachyOS RTX 4070 evidence.

## Qualification and material limitations

- Linux backend Qwen English/Spanish, offline Parakeet and bounded capture checks
  passed. Remaining packaged UI and deferred lifecycle/update acceptance was
  confirmed manually by the user. Agent execution limits and historical platform
  results are retained in the qualification report.
- The reported Linux microphone reset to 50% did not reproduce in measured checks:
  selected source volume remained 48%. The user accepted retaining current gain
  behavior and closed the investigation; no reset root cause is claimed and no
  gain defaults or persistent device settings were changed.
- Local Qwen language detection is probabilistic. Very short, mixed or ambiguous
  transcripts can fail admission. UTF-8 context estimates remain heuristic;
  arbitrary oversized segments/large merges are not qualified.
- No new performance/accuracy superiority claim, 60-minute Linux soak, Ubuntu
  recording/secret-storage acceptance, AUR publication or notarization is included.
