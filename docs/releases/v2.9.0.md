# AvaNevis v2.9.0

AvaNevis v2.9.0 is a local-first maintenance and UX release: Electron 44, explicit capture-mode selection, an Omarchy-inspired visual refresh, and evidence-gated Linux CUDA add-ons.

## What's New

### Capture modes

- **Mic + desktop remains the primary Start action.** Explicit **Mic Only** and **Desktop Only** actions never silently capture the other source.
- Dual-track spill, bounded stop finalization, and interrupted-session recovery are unchanged.

### Linux Core Beta and optional CUDA

- **Supported Linux targets** are Omarchy 4 and CachyOS x86_64 on Hyprland/Wayland + PipeWire. Other distributions remain experimental betas.
- Transcription still defaults to CPU `faster-whisper`. Users with a visible NVIDIA GPU on x86_64 can install a managed CUDA 12 runtime from Settings. While that runtime exists, transcription is fail-closed CUDA until Repair or Uninstall.
- **Speaker identification on Linux is Speakrs-only and CUDA-only.** Pyannote stays unavailable. There is no CPU fallback.
- **Local Qwen summaries on Linux are CUDA-only** after the same managed-runtime gate. There is no cloud path.
- Linux CUDA evidence is limited to CachyOS x86_64 + RTX 4070; other NVIDIA hosts are best-effort.

### App runtime and UX

- Electron 44.1.0 with electron-builder 26.15.3.
- Visual-system refresh: denser tokens and layout foundations while keeping the three-tab / icon-rail shell.
- Dependency hygiene: `filelock` 3.32.3 across platforms, plus accepted Python and npm upgrades recorded in the v2.9 compatibility matrix.

## Platform Support

- **Windows:** Windows 10/11 x64
- **macOS:** macOS 14+ on Apple Silicon. macOS 14.2+ uses the CoreAudio process tap; earlier macOS 14 releases use ScreenCaptureKit fallback. Packaged builds are Apple Silicon (`arm64`) only.
- **Linux Core Beta:** Omarchy 4 and CachyOS x86_64 (Hyprland/Wayland + PipeWire)

Ubuntu/Debian-family, vanilla Arch, Fedora Workstation, SteamOS Desktop Mode, other CachyOS desktops, and extra desktops are experimental betas. Refer to [Linux experimental support](https://github.com/AmirArshad/meeting-transcriber/blob/master/docs/guides/LINUX_EXPERIMENTAL.md).

## Notes

- Recording and transcription remain local. AvaNevis sends no meeting audio to a cloud service and includes no telemetry.
- Linux CUDA wheels and add-on model packs are explicit setup-time downloads, not installer-bundled.
- The planned 60-minute Linux soak was cancelled; it was not run or represented as passed.
- Ubuntu desktop recording and `safeStorage` hardware smoke remains an open follow-up.
