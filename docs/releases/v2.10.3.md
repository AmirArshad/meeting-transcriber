# AvaNevis v2.10.3

AvaNevis 2.10.3 updates bundled dependencies and fixes cleanup after a cancelled
summary-model download. Recording, transcription, speaker identification and
summaries remain local.

## Changes

- Update Electron to 45.2.1 and refresh the packaging and bundled Python
  dependencies, including certificate and security maintenance.
- Update CTranslate2 to 4.8.5 and ONNX Runtime to 1.31.1 in the Windows and
  Linux base transcription environments, and update the paired macOS MLX and
  MLX Metal runtimes to 0.32.4. The separate managed add-on runtimes retain
  their own dependency sets.
- Update hf-xet to 1.8.0 in the base Python packages and the separate macOS
  Parakeet runtime. Hugging Face model downloads continue to use the standard
  HTTPS path: native Xet acceleration remains disabled pending independent
  certificate-trust and telemetry qualification.
- Remove temporary Hugging Face download files after cancellation once the
  downloader process has exited. A cancelled setup preserves an existing
  summary runtime.
- Update the Speakrs CLI's ZIP dependency and retain checksum and extraction
  protections for downloaded artifacts.

## Upgrading

Install 2.10.3 on each machine. Existing recordings, transcripts and model
files remain in user data. The macOS Parakeet runtime lock has changed; if
Parakeet reports that repair is needed, use its **Repair** action in Settings.
The repair downloads and verifies the managed runtime again.

Windows installers remain unsigned, and macOS packages are ad-hoc signed and
not notarized. For Linux, continue to follow the supported and experimental
desktop distinctions in the [Linux guide](../guides/LINUX_EXPERIMENTAL.md).

## Validation

The [dependency qualification record](../development/DEPENDENCY_SWEEP_2026-11-03.md)
describes the platform tests and their limits. Model downloads are explicit;
no cloud transcription, background uploads or telemetry are introduced.
