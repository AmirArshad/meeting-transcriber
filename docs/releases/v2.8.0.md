# AvaNevis v2.8.0

AvaNevis now ships a Linux x86_64 Core Beta, while preserving its privacy-first, fully local recording and transcription workflow.

## What's New

### Linux Core Beta

- **Omarchy 4 support** — Pulse/PipeWire device discovery and microphone plus desktop-audio capture are available on the supported x86_64 Omarchy 4 target.
- **Durable Linux recordings** — microphone and desktop tracks spill to durable capture spools, recover after interruption, and are mixed only after recording stops.
- **CPU-only local transcription** — Linux uses `faster-whisper` on CPU. No Linux CUDA path is advertised or enabled in this release.
- **Linux packages** — GitHub Releases now include an x86_64 AppImage, a pacman package, and an experimental Debian `.deb` package. The AppImage does not depend on the legacy host `fuse2` library.
- **Platform-aware update choice** — installed Linux systems are directed to the matching package type, with AppImage as the safe fallback for unsupported or unknown distributions.

### Reliability and packaging hardening

- Linux recording errors follow the existing structured stdout contract, including recoverable paths where a final or temporary audio file exists.
- Device IDs stay opaque on Linux, so Pulse source and monitor identifiers are never coerced through numeric parsing.
- The tray uses Linux-native assets and retains an accessible taskbar fallback when a StatusNotifierItem host is unavailable.
- Packaged resource checks now cover the Linux Python runtime, ffmpeg, backend sources, legal notices, AppImage runtime, pacman metadata, and Debian control metadata.
- `filelock` is updated to 3.32.3 across development and packaged runtime requirements.

## Platform Support

- **Windows:** Windows 10/11 x64
- **macOS:** macOS 13+ on Apple Silicon
- **Linux Core Beta:** Omarchy 4 x86_64

Ubuntu/Debian-family, vanilla Arch, CachyOS, Fedora Workstation, and SteamOS Desktop Mode are experimental betas. Refer to [Linux experimental support](https://github.com/AmirArshad/meeting-transcriber/blob/master/docs/guides/LINUX_EXPERIMENTAL.md) for package choices and known limitations.

## Notes

- Linux speaker identification and local summaries remain visible but disabled as unsupported. There is no CPU fallback for those add-ons.
- The planned 60-minute Linux soak was cancelled; it was not run or represented as passed.
- Ubuntu desktop recording and `safeStorage` hardware smoke, visual Linux tray-icon verification, and unplugged-endpoint filtering hardware verification remain open follow-ups.
- Recording and transcription remain local. AvaNevis sends no meeting audio to a cloud service and includes no telemetry.
