# AvaNevis v2.12.0

Use **Import audio** in History to open one local WAV, MP3 or Opus file. Confirm the transcription engine and language before starting. AvaNevis saves a playable copy, queues transcription on your device and leaves the original file in place.

- Play imported audio from History while transcription runs. Follow the job in Activity, or open the transcript when it is ready.
- Cancel an import while AvaNevis prepares the audio. After the copy is saved, cancel or retry transcription in Activity while keeping the audio.
- Open History meetings from the keyboard. Activity actions wrap on narrower windows.
- Fixed a Windows import save error and a brief Resume prompt after a transcription job finishes.
- Electron advances to 46.0.0-alpha.11. The Linux bundle uses Python 3.11.18. The Python build closures and macOS Parakeet lock also include dependency updates.

Existing macOS Parakeet installations need **Repair** in Settings after the lock update. macOS still requires Apple Silicon and macOS 15 or later.

Transcript exports remain available in Markdown and plain text. SRT and WebVTT are deferred until saved transcripts retain sufficiently precise timing. Summary generation continues to start from the explicit **Generate summary** action.

See the qualification record for CachyOS and Windows 11 evidence, dependency holds and the remaining platform checks. [v2.12.0 qualification](../development/V2_12_QUALIFICATION.md)
