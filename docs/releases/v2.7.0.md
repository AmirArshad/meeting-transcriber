# AvaNevis v2.7.0

Token-free Speakrs speaker identification — choose Speakrs or Pyannote in Settings. Only one engine is installed at a time.

## What's New

### Speakrs speaker identification

- **Engine selector** — Settings → Speaker Identification now offers two exclusive options: **Speakrs** (token-free; Recommended) or **Pyannote** (`pyannote/speaker-diarization-community-1` with your own Hugging Face token).
- **New installs default to Speakrs.** Existing Pyannote setups stay on Pyannote until you switch. There is no silent cutover.
- **One engine at a time** — switching uninstalls the other engine’s models so they cannot run side by side.
- **Token handling** — Speakrs never needs a Hugging Face token. Switching Pyannote → Speakrs **keeps** a saved token so you can switch back without pasting it again. **Remove** still deletes the token.
- **Same guided transcription path** — when speaker identification is Ready, AvaNevis still finds speakers first, then transcribes padded speaker windows with Whisper. If that guided path fails, you keep a normal transcript and a speaker-label error in meeting metadata.
- **Platforms** — Speakrs: Windows CUDA and macOS Apple Silicon CoreML. Pyannote: Windows CUDA and macOS Apple Silicon MPS. Neither engine falls back to CPU.
- **Smaller Speakrs download** — Windows Speakrs is about **823 MB** (model pack + ONNX Runtime) versus roughly 2–4 GB for Pyannote. RAM: **8 GB minimum, 16 GB recommended**.
- **Credits** — Settings → About and bundled third-party notices name Speakrs (Apache-2.0) and the bundled `speakrs-cli`.

### Also in this release

- Electron **42.9.0** (security patches; still Electron 42, not 43).
- Windows recordings-folder path matching so speaker sidecar JSON writes succeed when the folder is reached via a junction, 8.3 name, or `\\?\` prefix.
- Windows ffmpeg 8.0.1 pin retargeted to the Gyan GitHub release (same binary checksum).
- Python pin bumps: `filelock`, `certifi`, `typing-extensions`, `ctranslate2`.

## Platform Support

- Windows 10/11 x64
- macOS 13+ on Apple Silicon

## Notes

- Speaker identification remains an **optional local add-on**. Setup is always an explicit action — no background downloads.
- Speakrs can over-cluster or split identity on mixed in-room + playback audio. Pyannote stays available for that reason. We do not claim a Windows speed or accuracy win versus Pyannote CUDA.
- Only one live recording at a time; overlapping capture is still unsupported.
- Mic and desktop tracks remain separate until post-recording mix.
- Whisper models still download on first use unless already cached.
- GPU acceleration is used automatically when supported (CUDA on Windows, Metal on Apple Silicon).
- Meeting summaries remain a separate, user-triggered local add-on.

## Privacy

- Zero telemetry
- No cloud transcription
- No account required
- Speakrs setup is token-free. Pyannote still uses **your** Hugging Face token only — AvaNevis does not ship, proxy, or log a maintainer token.
