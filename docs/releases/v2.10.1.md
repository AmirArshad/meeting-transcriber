# AvaNevis v2.10.1

AvaNevis v2.10.1 is a maintenance patch on v2.10.0: History interaction fixes,
faster post-stop finalization, and the October 2026 dependency/security
maintenance with its cross-platform host qualification. No new features, cloud
processing, telemetry, or background uploads were added; all meeting processing
remains local. Decisions, evidence, and limits are in the
[maintenance record](../development/DEPENDENCY_MAINTENANCE_2026-10.md).

## Changes

- History fixes: summary cancellation clicks now register, captions no longer
  leak across meetings, clipped History layouts are corrected, and the History
  detail view shows the transcript language name separately from the
  transcript and summary actions.
- Post-stop finalization is faster: when no `ffprobe` is available (as in the
  packaged layout) the encoder no longer performs a redundant second Opus
  decode, and encoder effort is reduced. Interrupted-capture recovery still
  deletes a capture only after a real Opus decode succeeds; a developer
  `ffmpeg` on `PATH` is never rewritten by the speedup.
- Electron 44.7.0 and electron-builder 26.17.0, the latter qualified with
  native Windows NSIS install/uninstall and read-only macOS DMG payload
  verification (a default-off manual CI mode retains those installer checks).
  The long-standing moderate sprintf-js advisory (GHSA-hp3w-g68c-fv3c) is
  closed: an npm override moves the build-time-only `global-agent@3`
  dependency of `@electron/get` to global-agent 4, which drops the
  roarr/sprintf-js chain entirely. `npm audit` now reports zero
  vulnerabilities. The only call site (`bootstrap()`) was verified against
  the v4 API, including with proxy use enabled.
- Speakrs CLI Cargo tree: rustls updated 0.23.45 → 0.23.46, clearing four
  October RustSec advisories. Three zip 6.0.0 extraction advisories are
  ignored in `native/speakrs-cli/.cargo/audit.toml` with a dated
  justification: the only consumer (ndarray-npy, pinned by Speakrs) reads
  archive entries in memory and never calls the vulnerable extraction
  APIs, and the parent pins cap zip below the fixed major line.
  `cargo audit --deny warnings` passes.
- FFmpeg 8.1.2 on Windows, macOS, and Linux, with the matching bundled source
  pin. Opus encode, decode-before-delete recovery, and meeting import checks
  passed on all three platforms (CachyOS and Windows on 2026-10-09, macOS on
  2026-10-17).
- Bundled CPython updated to 3.11.17 on macOS and Linux. Windows remains on
  the official embedded 3.11.9; no official 3.11.17 embedded archive exists
  and a replacement layout is a separate qualification.
- CTranslate2 4.8.2 on Windows and Linux with matching CUDA/CPU transcripts
  recorded against the prior pin. CTranslate2 4.8.3 remains held pending
  CUDA/Windows teardown qualification.
- ONNX Runtime 1.31.0 for the base (Silero VAD) runtime on Linux and Windows,
  with telemetry suppression forced before native startup in ordinary and
  isolated Python children. Linux qualification matched 1.30.0 VAD
  probabilities and speech boundaries with no network syscalls under
  `strace`; the Windows native gate recorded 20 ETW events unsuppressed and
  zero with the pre-import guard. Managed Speakrs and Parakeet ONNX artifacts
  keep their separately qualified pins.
- Parakeet macOS runtime lock regenerated for msgpack 1.2.3 and urllib3 2.8.0
  (real wheel bytes, verified hashes). Runtimes installed under the old lock
  report repair-required, and repair/removal prunes superseded generations.
- Pyannote add-on closure updated to pyannote.audio 4.0.7 with Torch 2.13.0,
  torchaudio 2.11.0, and TorchCodec 0.16.0, clearing the published Torch
  advisories. Existing Pyannote installs report out of date and need setup
  again before use; Speakrs installs are unaffected.
- Compatible Dependabot updates applied across the base Python pins (including
  filelock 4.1.1, tokenizers 0.23.3, and the coordinated MLX/MLX Metal 0.32.3
  pair), with Python 3.11 ceilings, grouped future proposals, SHA-pinned CI
  Actions, and CI dependency audits on all three platforms. All three Python
  build inventories audit clean.

## Platform support

- Windows 10/11 x64.
- macOS 14+ on Apple Silicon; arm64 packages only. Packages remain ad-hoc
  signed, not notarized.
- Linux Core Beta: Omarchy 4 and CachyOS x86_64, Hyprland/Wayland + PipeWire.
  Other distributions/desktops remain
  [experimental betas](../guides/LINUX_EXPERIMENTAL.md). Release builds
  include AppImage, pacman, and experimental deb artifacts.

## Qualification and material limitations

- Host gates passed on Windows (2026-10-08/09), CachyOS (2026-10-08/09), and
  macOS (2026-10-09, FFmpeg 8.1.2 follow-up 2026-10-17), and the final
  dependency batches passed all 13 native CI jobs, including the Windows
  NSIS installer and ONNX startup-telemetry guards. The full local gate on
  macOS at release preparation passed 1,125 JS / 847 Python tests with
  4 / 9 platform skips. The full manual recording and local-AI checklists
  were not repeated for this patch.
- In the 2026-10-17 macOS FFmpeg session the CoreAudio tap delivered silence
  under both the dev and packaged recorders, so desktop-content capture was
  not re-qualified there; the microphone track carried real audio and
  desktop capture remains qualified by the 2026-10-09 macOS gate. This is
  upstream of, and unaffected by, the FFmpeg version.
- Real Windows Pyannote diarization with a user token and the gated model
  remains unqualified; only random-weight CUDA inference and the macOS MPS
  qualification were run. Existing Windows Pyannote users should re-run
  setup and treat diarization as unverified until that check is recorded.
- Three zip extraction advisories (RUSTSEC-2026-0367/0368/0369) remain
  open upstream for the Speakrs-pinned zip 6 line and are carried as a
  reviewed audit ignore (review by 2027-01-31, or on the next Speakrs
  update): the vulnerable `extract()` APIs are never called, and archives
  are read in memory only. This is build/host tooling exposure only; the
  shipped CLI receives local model files, not downloaded archives.
- No AUR publication, Apple notarization, Ubuntu desktop acceptance, or new
  hardware/performance claims are included in this patch.
