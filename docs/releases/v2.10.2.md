# AvaNevis v2.10.2

AvaNevis v2.10.2 updates certificate trust after the October 2026 eMudhra
intermediate-CA compromise. Recording, transcription, diarization and summaries
remain local. Install the rebuilt application to update its bundled trust
dependencies; an operating-system or browser update alone does not replace them.

## Changes

- Electron 44.9.2, including the compiled certificate public-key blocklist for
  Chromium and Node TLS/HTTPS. The update checker and JavaScript artifact
  downloads use Node HTTPS, so browser-only revocation is insufficient.
- certifi 2026.10.19 in packaged Windows, macOS and Linux Python environments.
- pip 26.2.2, including its separate vendored certificate bundle. Build
  preparation replaces the pip already present in standalone Python as well as
  bootstrapping embedded Windows Python. The wheel remains SHA-256 pinned.
- The macOS Parakeet certifi wheel and complete extracted-file inventory are
  regenerated from verified upstream bytes, producing a new runtime lock digest.
- Managed Pyannote environments explicitly require certifi 2026.10.19. Saved
  dependency markers without this requirement report out of date.
- Speakrs CLI dependencies: rustls-webpki 0.103.16, webpki-roots 1.0.10 and
  webpki-root-certs 1.0.10. The legacy webpki-roots 0.26 compatibility package
  resolves through the updated 1.0.10 bundle. Its version-only RustSec finding
  has a dated, regression-guarded exception; see the maintenance record.
- Hugging Face model downloads use the standard HTTPS transport with patched
  certifi. Native Xet acceleration is disabled until its separate TLS stack is
  patched and qualified; large downloads can take longer. Existing catalog
  checksum and offline-compute requirements remain enforced.

## Upgrading

- Install v2.10.2 on each machine and keep the operating system and browser
  current, including Linux certificate/NSS packages.
- Existing recordings and transcripts are preserved. Cached models remain usable
  offline; this incident alone does not establish that they were modified.
- If Pyannote or macOS Parakeet reports that setup needs repair, run its explicit
  setup/repair action in Settings. Replacing the app alone does not rewrite
  optional runtimes stored in the user-data directory.
- Certificate failures during downloads should be investigated; do not disable
  certificate verification to work around them.

## Validation and limits

The [maintenance record](../development/CERTIFICATE_TRUST_MAINTENANCE_2026-10.md)
tracks local checks, compatibility evidence and remaining release gates. Native
Windows/macOS packaging and GitHub CI must pass before tagging. This patch does
not add hardware acceptance or GPU-performance claims. Windows installers remain
unsigned and macOS packages remain ad-hoc signed without notarization.

Incident details: [eMudhra intermediate CA compromise](https://emudhra.we-have-a-problem.com/).
