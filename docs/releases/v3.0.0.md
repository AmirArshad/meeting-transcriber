# AvaNevis v3.0.0

AvaNevis 3.0.0 is a private, local Audio Recorder & Transcriber for microphone, desktop audio, and imported audio files, adding full-text History search, grounded local Chat with timestamp citations, subtitle exports, and an in-app auto-updater.

- **Local History search & grounded Chat:** Search across saved transcripts and summaries with a disposable local SQLite FTS5 index and jump straight to matching timestamps (no AI add-ons required). When **Summaries & Chat** is set up, open **Chat** from the left rail (`Ctrl/Cmd+Shift+3`) or **Ask in Chat** from History to ask questions backed by lazy local `llama-server` inference (`llama-cli` fallback), manual and automatic idle memory unload, and clickable timestamp citations that seek the source recording.
- **Caption-scale timing & subtitle exports:** New recordings and imported audio persist caption-scale timing sidecars tied to the saved transcript hash, enabling accurate `.srt` and `.vtt` (WebVTT) subtitle exports alongside `.md` and `.txt`.
- **Modern in-app auto-updater:** Differential in-app updates with recording- and AI-safe restart gates on Windows NSIS and Linux AppImage, copyable `pacman` / `apt` upgrade commands on Linux package installs, and manual `.dmg` download on ad-hoc macOS builds (Squirrel.Mac in-app updates activate automatically on Developer ID signed builds).
- **Audio Recorder & Transcriber positioning and UI polish:** Updated user-facing copy, responsive Settings and dialog layouts, and refined navigation and recording controls.
- **Runtime & reliability upgrades:** Unified bundled Astral CPython `3.11.18+20261110` across Windows, macOS, and Linux; decoupled History scan/recovery locking to eliminate metadata lock contention during slow recovery scans; and fixed recovered-capture duration preservation (including legacy captures without a transcription handoff).

### Installation

- **Windows (unsigned installer):** Download and run `AvaNevis-Setup-3.0.0.exe`. Because the v3.0.0 Windows installer is unsigned, Windows Defender SmartScreen may warn on first run — choose **More info** then **Run anyway**.
- **macOS (Apple Silicon, macOS 15+, ad-hoc signed & not notarized):** Download `AvaNevis-Setup-3.0.0.dmg` and drag AvaNevis into Applications. Because v3.0.0 macOS builds are ad-hoc signed and not notarized, if Gatekeeper blocks launch, open **System Settings → Privacy & Security → Open Anyway** after attempting to open it (<https://support.apple.com/en-us/102445>). Grant Microphone and Screen & System Audio Recording permissions when prompted.
- **Linux (x86_64 Core Beta):** Run the `AvaNevis-Setup-3.0.0.AppImage`, install `AvaNevis-Setup-3.0.0.pkg.tar.zst` on Arch/CachyOS/Omarchy (`sudo pacman -U ...`), or try the experimental `.deb` (`sudo apt install ./AvaNevis-Setup-3.0.0.deb`).

Electron remains on `46.0.0-alpha.11` (stable Electron 46.x is still unpublished as of 2026-11-21) and FFmpeg remains on matched `8.1.2` across all three platforms. See the qualification record for CachyOS Linux, Windows 11, and macOS arm64 evidence, dependency holds, and the explicitly accepted v3.0.0 limits: Windows 10, macOS 15, isolated Keychain migration, permission-prompt variants, gated Pyannote, representative natural-speech Speakrs separation, live signed updater verification, and optional code signing/notarization remain unqualified or deferred.
